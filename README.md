A 2D platformer game made in Godot 4.7 for Hack Club Jumpstart.

Run, jump, and collect coins to fill your progress bar.

## Controls

| Action | Key |
|--------|-----|
| Move left | Left Arrow |
| Move right | Right Arrow |
| Jump | Up Arrow |

## Gameplay

Move around the level and touch coins to collect them. Each coin adds to your
progress bar. If you miscalculate the jump and fall down, you will need to
climb all the way back up.

## Built With

- [Godot Engine 4.7](https://godotengine.org/)
- GDScript

## Running the Project

1. Install [Godot 4.7](https://godotengine.org/download) or later
2. Clone this repository
3. Open Godot, click **Import**, and select the `project.godot` file
4. Press **F5** (or the Play button) to run the game
